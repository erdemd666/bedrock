When a PC does not start

For a machine that powers on but never shows a picture, beeps, or shows a code on the board. Work through it from the top: most dead PCs are one loose or failed part, and the order below finds it fastest.

1. First checks

  1. Safety. Switch the power supply off at its rear switch and unplug the mains cable before you touch anything inside. Hold the power button for five seconds to drain what is left. Touch bare metal on the case before handling parts.
  2. Write down what you see and hear when you press the power button: fans spin or not, lights on the board and their colour, beeps (count them, note long and short), a two-digit display. The tables below turn that into a part.
  3. The monitor. Is the cable in the graphics card, not the board's own video port (a card disables the board port on most desktops)? Is the monitor on the right input? Try another cable.
  4. Power connectors. The wide 24-pin plug and the 4- or 8-pin CPU plug near the processor must both be in and latched. A missing CPU plug gives fans but nothing else.
  5. Recent change? If it stopped after new memory, a new card or a BIOS setting (memory overclock such as XMP or EXPO), undo that first.
New memory or a new CPU can take several minutes on the first start while the board trains the memory, with a black screen. Wait five minutes before you call it dead.

2. The minimum-parts test

Strip the machine to the parts it needs to reach the BIOS screen, then add parts back one at a time. The part that brings the fault back is the faulty one.

Step 1: power supply

  • No lights and no fans at all: check the wall socket, the mains cable and the rear switch. Then check the front-panel power button wires (labelled PWR_SW on the board): briefly touching the two PWR_SW pins with a screwdriver does the same as the button. If that starts it, the case button is faulty.
  • Fans spin for a second and stop, or the machine clicks and restarts: often a short. Remove everything but the board, CPU, cooler and one memory module, and lift the board out if a stray standoff under it may touch the back.
  • A multimeter on the 24-pin plug, with the machine on, should read about +12 V on yellow wires, +5 V on red, +3.3 V on orange, and +5 V on purple even when the machine is off but plugged in (standby). Readings more than 5% off point to the power supply. The surest test is a known-good power supply of the same type.

Step 2: strip it down

  1. Leave connected only: board, CPU with its cooler (fan plugged into CPU_FAN), one memory module, power supply (24-pin and CPU plug) and the power button.
  2. Remove every card, disk, USB device and front-panel USB or audio cable. If the CPU has graphics built in, remove the graphics card too and connect the monitor to the board.
  3. Start it. If you now reach the BIOS screen (or get a "no boot device" message), the board, CPU, memory and power supply work: add the other parts back one at a time.

Step 3: one memory module per slot

  1. Use the slot the board manual names for a single module (often the second slot from the CPU, labelled A2 or DIMM_A2). Press until both latches click.
  2. Try each module alone in that slot. A module that fails in every slot is bad.
  3. Take one good module and try it in every slot. A slot that never works means the slot, the board, or the CPU's memory controller; check the CPU socket for bent pins.

Step 4: clear the BIOS settings (CMOS)

  1. With the mains cable unplugged: use the board's CLR_CMOS button or jumper (see the board manual), or take out the coin cell (CR2032) for five minutes.
  2. If the clock resets to an old date every time the mains is unplugged, replace the coin cell.

Step 5: outside the case

Place the board on its cardboard box (never on the anti-static bag, which can conduct) with the minimum parts from step 2. If it starts there but not in the case, something in the case is shorting it: an extra standoff, a loose screw, or a damaged front-panel cable.

Still dead with a known-good power supply and a known-good memory module, in the minimum setup, outside the case: the board or the CPU is faulty. Bent socket pins, a swollen capacitor or a burnt smell near the CPU power stage point to the board.

3. Board debug lights

Many boards from about 2017 on have four small lights, labelled CPU, DRAM, VGA and BOOT, near the memory slots or the 24-pin plug. During a normal start they come on one after another and go out. The light that stays on shows where the start stopped.

Light onMeaningTry
CPUNo CPU detected, or the CPU failedCheck the CPU power plug; reseat the CPU; check the socket for bent or dirty pins; try another CPU the board supports
DRAMNo memory detected, or memory failedReseat the memory; one module at a time; clean the contacts; use the slots the manual names
VGANo graphics detected, or graphics failedReseat the card and its power plugs; clean its contacts; try another card. With built-in graphics, reseat the CPU
BOOTNo boot device, or it failedReseat SATA cables at both ends or the M.2 drive and its screw; try another cable, port or drive

Source: ASUS, "ASUS motherboard troubleshooting via Q-LED indicators" (support FAQ 1042678). MSI board manuals (for example the MEG X570 ACE user manual, "EZ Debug LED") describe the same four lights: each indicates that component "is not detected or fail".

5. Beep codes by BIOS

Beeps need a speaker: many cases have none. A small piezo buzzer on the board's SPEAKER pins costs little and is worth having. The BIOS maker's name is on the start-up screen and in the board manual.

Phoenix BIOS

We could not obtain a Phoenix document to cite, so no generic Phoenix table is given here. Phoenix uses groups of beeps such as 1-3-1 (one beep, pause, three, pause, one). Dell's older machines use this style: see the older Dell beep table below, and the board or PC maker's manual for others.
